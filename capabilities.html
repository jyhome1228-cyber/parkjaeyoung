02 / CAPABILITIES

전략을 세우고, 설계하고,
직접 구현합니다.잘하는 일 · Capabilities

브랜드와 시각 언어를 만드는 일부터 웹과 시스템을 구현하는 일까지 직접 다룹니다. 실무의 경험은 연구·교육·심사·글쓰기로 확장합니다.

CORE PRACTICE

디자인과 개발을 하나의 실행 과정으로 연결합니다.

01

Branding

브랜딩 · 브랜드 전략

브랜드의 방향을 정의하고 네이밍, 아이덴티티, 패키지와 운영 가능한 브랜드 시스템으로 연결합니다.

Strategy · Naming · Identity · Package
02

Visual Design

시각디자인 · 커뮤니케이션 디자인

그래픽, 편집, 디지털 콘텐츠와 아트디렉션을 통해 정보와 브랜드의 메시지를 시각적으로 구조화합니다.

Graphic · Editorial · Digital · Art Direction
03

Front-end Development

프론트엔드 개발 · 웹 인터페이스 구현

HTML, CSS, JavaScript를 기반으로 디자인을 반응형 웹과 실제 인터랙티브 화면으로 구현합니다.

HTML · CSS · JavaScript · UI
04

Full-stack Development

풀스택 개발 · 디지털 시스템 구축

웹사이트를 넘어 관리자, CRM, 데이터 연동과 운영 기능까지 필요한 디지털 시스템을 설계하고 구축합니다.

Web · Admin · CRM · Data

PROFESSIONAL PRACTICE

실무 경험을 연구와 교육, 평가와 언어로 확장합니다.

05

Research

연구 · 논문

브랜딩, 디자인, 생성형 AI와 디지털 경험을 중심으로 실무에서 발견한 질문을 연구와 논문으로 발전시킵니다.

Design · AI · Branding · Visual Communication
06

Education & Lecture

교육 · 대학 강의 · 멘토링

대학 강의와 캡스톤, 워크숍, 프로젝트 멘토링을 통해 실무와 연구의 경험을 교육으로 연결합니다.

University · Lecture · Workshop · Mentoring
07

Jury & Evaluation

심사 · 평가 · 컨설팅

공공기관, 기업, 지역 브랜딩과 창업지원 프로젝트를 사용자 관점, 메시지 전달력과 실행 가능성을 기준으로 평가합니다.

Jury · Review · Evaluation · Consulting
08

Writing

글쓰기 · 작가 활동

브랜드, 스타트업, 소비 경험과 개인 성장에 대한 생각을 글로 정리하며 시각적 판단을 언어로 설명합니다.
